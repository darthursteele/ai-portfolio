# AI Portfolio — David Steele

I'm a product manager who builds with AI tools directly — not just scoping work for engineers, but designing and deploying the prompts, agents, and pipelines myself. This repo is the evidence.

The work here spans three layers: **prompt engineering** (production-grade prompts built to solve real problems), **agentic systems** (multi-agent CrewAI pipelines), and **skills** (prompts packaged into deployable one-click agents — in progress).

## What's Here

### [`/showcase`](./showcase/README.md) — Curated Prompt Portfolio
14 production-grade prompts across six domains, each selected for what it demonstrates technically: structured output design, multi-agent pipeline thinking, anti-hallucination discipline, rubric-based evaluation, or real-world utility.

A few highlights:

- **[Job-search pipeline](./showcase/career/)** — Three prompts with JSON schema handoffs: company intelligence brief → competitiveness assessment → cover letter. The company brief outputs machine-readable JSON with confidence labels (`high / medium / low / speculation`) on every factual claim, borrowed from intelligence analysis methodology. Built for my own active job search.

- **[App viability assessment](./showcase/market-research/app-viability-assessment.md)** — A 100-point scoring rubric across four sub-dimensions that lets you compare completely different app ideas on the same axis. TAM/SAM breakdown, path-to-$100M section, and cross-idea comparison design.

- **[Couture photo director](./showcase/marketing/couture-photo-director.md)** — Model-adaptive image generation agent (Midjourney v6, DALL-E 3, SDXL, Ideogram v2). Accepts reference images of garments, outputs a full shot list with camera specs, lighting design, styling direction, and budget-tier feasibility. Built for a real marketing automation project.

- **[Shower inspection (CA)](./showcase/safety-inspection/shower-inspection-ca.md)** — Evidence-only analysis with a seven-rule anti-hallucination protocol. Every finding cites specific CA code. Confidence thresholds per photo. *"Prefer silence over guesswork when confidence < threshold"* — a pattern that belongs in any high-stakes prompt.

- **[Business coach persona](./showcase/ai-behavior/business-coach.md)** — Defines not just a persona, but *when that persona should change register*. Escalation triggers for when to become more direct and urgent. That's meta-behavior design, not just character definition.

### [`/agentic`](./agentic/README.md) — CrewAI Framework
A production-ready multi-agent development environment built on [CrewAI](https://github.com/joaomdmoura/crewai). Three working crew implementations (research, content analysis, creative writing), a crew factory pattern, performance monitoring, structured logging, Docker configuration, and a CI/CD pipeline.

One meta-detail worth noting: this framework wasn't scaffolded by hand. It was generated by [`/prompts/crewai_repo_prompt.md`](./prompts/crewai_repo_prompt.md) — a prompt that takes a project name and a few config flags and outputs a complete production-ready CrewAI repository. The generator and the output both live in this repo.

```bash
cd agentic
python main.py --list-crews          # see available crews
python main.py --crew research --topic "AI in product management"
make help                             # all available commands
```

## Design Principles

A few things that show up consistently across this work:

**Anti-hallucination by design.** The shower inspector, the company intelligence brief, the app viability rubric — all of them enforce explicit rules about what the model can and cannot claim. Confidence labeling, evidence-only constraints, silence-over-guesswork thresholds. High-stakes prompts should be engineered, not hoped.

**Pipeline thinking.** The job-search prompts were designed as a three-stage pipeline before they were written as individual prompts. The JSON schema that links the company brief to the cover letter generator isn't an afterthought — it was the design constraint that shaped both prompts.

**Rubric-based evaluation.** Prompts that return vague assessments aren't useful. The app viability assessment, brand foundations evaluator, and resume optimizer all force the model into specific, comparable outputs — scores with defined anchors, not impressionistic summaries.

**Economy of expression.** [`objective-skeptical-partner.md`](./showcase/ai-behavior/objective-skeptical-partner.md) is fewer than 100 words and completely changes the character of a conversation. [`humanize-writing.md`](./showcase/ai-behavior/humanize-writing.md) catalogs the specific sentence patterns and vocabulary clichés that give AI writing away — by name. Specificity matters more than length.
