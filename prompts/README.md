# Source Prompt Library

This directory contains the original working versions of the prompts in this portfolio — pre-curation, pre-polish, often written to solve a specific problem in the moment.

The curated and documented versions live in [`/showcase`](../showcase/README.md). If you want to understand a prompt's design choices, the showcase version is the right place to start. If you want the raw material or an earlier iteration, it's here.

## The Meta-Prompt

`crewai_repo_prompt.md` is worth calling out specifically. The `agentic/` framework in this repo wasn't scaffolded by hand — it was generated by running this prompt. The prompt takes a project name and a few configuration flags, then outputs a complete production-ready CrewAI repository: directory structure, base classes, configuration management, logging, CI/CD, Docker, and three working example crews.

It's a good illustration of how prompts can be tools, not just queries.
